# Персональний помічник

## 1. Встановлення та запуск

Для запуску з вихідного коду на Windows використовуйте Python 3.12–3.15. Команди нижче призначені для PowerShell. Якщо репозиторій уже клоновано, відкрийте його кореневу папку й перейдіть до кроку 2.

1. Клонуйте репозиторій і відкрийте папку проєкту.

   ```powershell
   git clone --branch develop https://github.com/ArtemKrylov/personal_helper.git
   Set-Location personal_helper
   ```

2. Перейдіть на гілку `develop` і завантажте останні зміни.

   ```powershell
   git switch develop
   git pull --ff-only origin develop
   ```

3. Перевірте версію Python, створіть віртуальне середовище й установіть залежності.

   ```powershell
   py --version
   py -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

4. Запустіть помічника з кореневої папки проєкту.

   ```powershell
   .\.venv\Scripts\python.exe -m main
   ```

   Після запрошення `Enter a command:` введіть `commands` для короткого списку або `help` для таблиці із синтаксисом і прикладами. Для виходу введіть `exit` або `close`.

### Збирання Windows-версії (.exe)

Після встановлення залежностей виконайте команду в кореневій папці проєкту. PyInstaller збере помічника в один консольний файл із піктограмою `icon.ico`.

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --onefile --console --icon=icon.ico --name PersonalHelper main.py
```

Готовий файл `dist/PersonalHelper.exe` можна запускати на Windows без окремого встановлення Python. Залиште його в папці `dist` усередині проєкту, щоб він використовував ту саму адресну книгу, що й версія з вихідного коду.

```powershell
.\dist\PersonalHelper.exe
```

### Робота над проєктом

Створіть гілку від оновленої `develop`. Після внесення змін надішліть свою гілку до репозиторію та відкрийте pull request до `develop`.

```powershell
git switch -c feature/your-feature-name
```

```powershell
git add .
git commit -m "feat: describe your change"
git push -u origin feature/your-feature-name
```

## 2. Робота з помічником

Це консольна програма для ведення адресної книги. Контакт може містити кілька телефонів, адресу, електронну пошту, дату народження й текстові нотатки. Нотатки належать контактам і можуть мати теги. Помічник завантажує адресну книгу під час запуску й зберігає її під час виходу. Обидві версії використовують файл `storage/addressbook.pkl` у корені проєкту незалежно від папки запуску.

- Ім’я в командах складається з одного слова, наприклад `Олена` або `Олена_Коваль`. Вводьте його з тим самим регістром літер, з яким зберегли контакт.
- Телефон має містити рівно 10 цифр від `0` до `9` без пробілів і роздільників. Дату народження вводьте у форматі `ДД.ММ.РРРР`, а електронну пошту у форматі на зразок `olena@example.com`.
- Адреса, текст нотатки й тег можуть складатися з кількох слів. У командах із символом `|` ставте пробіли з обох боків від нього. Для редагування, видалення або зміни тегів указуйте точний текст нотатки.
- Якщо помічник розпізнає друкарську помилку або український варіант команди на зразок `допомога`, він запропонує найближчу команду. Для підтвердження введіть `y`, для відхилення — `n`.

У таблиці `<…>` позначає обов’язковий аргумент, а `[…]` — необов’язковий. Кутові й квадратні дужки вводити не потрібно.

| Команда | Дія |
| --- | --- |
| `commands` | Показує короткий список назв команд. |
| `help [команда] [desc]` | Без аргументів показує таблицю всіх команд із синтаксисом і прикладами. `help add-birthday` показує синтаксис і приклад однієї команди, а `help add-birthday desc` — її опис. |
| `hello` | Виводить привітання. |
| `exit`, `close` | Завершує роботу та зберігає дані. |
| `add <ім’я> <телефон> [дата]` | Створює контакт із телефоном і, за потреби, датою народження. Якщо ім’я вже є в книзі, запитує підтвердження оновлення контакту. |
| `add-phone <ім’я> <телефон>` | Додає ще один номер до контакту. Якщо контакту немає, пропонує створити його. |
| `change-phone <ім’я> <старий номер> <новий номер>` | Замінює один номер контакту, зберігаючи решту. |
| `del-phone <ім’я> <телефон>` | Видаляє вказаний номер із контакту. |
| `change <ім’я> <телефон> [дата]` | Замінює всі номери контакту одним указаним номером. Якщо вказано дату, оновлює також день народження. |
| `del <ім’я>` | Видаляє контакт разом із його нотатками. |
| `show <ім’я>` | Показує контакт за точним ім’ям. |
| `phones <ім’я>` | Показує телефони контакту. |
| `all` | Показує таблицю всіх контактів. |
| `add-birthday <ім’я> <дата>` | Додає день народження. Для заміни наявної дати запитує підтвердження. |
| `show-birthday <ім’я>` | Показує день народження контакту. |
| `change-birthday <ім’я> <дата>` | Задає нову дату народження. |
| `del-birthday <ім’я>` | Видаляє дату народження з контакту. |
| `birthdays [кількість днів]` | Показує дні народження за вказану кількість календарних днів, включно із сьогоднішнім. Введіть ціле число від 1. Типове значення — 7 днів. |
| `add-address <ім’я> <адреса>` | Записує адресу контакту. Для заміни наявної адреси запитує підтвердження. |
| `show-address <ім’я>` | Показує адресу контакту. |
| `change-address <ім’я> <нова адреса>` | Оновлює адресу контакту. |
| `del-address <ім’я>` | Видаляє адресу з контакту. |
| `show-all-addresses` | Показує імена й адреси контактів, у яких записано адресу. |
| `add-email <ім’я> <email>` | Додає електронну пошту. Для заміни наявної адреси запитує підтвердження. |
| `show-email <ім’я>` | Показує електронну пошту контакту. |
| `change-email <ім’я> <новий email>` | Задає нову адресу електронної пошти. |
| `del-email <ім’я>` | Видаляє електронну пошту з контакту. |
| `add-note <ім’я> <текст>` | Додає текстову нотатку до контакту. |
| `search-notes <текст>` | Шукає фрагмент тексту в нотатках усіх контактів без урахування регістру літер. |
| `edit-note <ім’я> <старий текст> \| <новий текст>` | Змінює текст нотатки. |
| `del-note <ім’я> <текст>` | Видаляє нотатку з контакту. |
| `add-tag <ім’я> <текст нотатки> \| <тег>` | Додає тег до нотатки. |
| `del-tag <ім’я> <текст нотатки> \| <тег>` | Видаляє тег із нотатки. |
| `search-tags <тег>` | Знаходить нотатки за повною назвою тегу без урахування регістру літер. |
| `sort-tags` | Показує нотатки за абеткою тегів. Нотатка з кількома тегами з’являється в списку під кожним із них. |

Приклад сеансу після запуску помічника.

```text
add Олена 0671234567 15.09.2000
add-phone Олена 0501234567
change-phone Олена 0501234567 0507654321
add-address Олена вул. Шевченка, 10
add-email Олена olena@example.com
add-note Олена Замовити книжку
add-tag Олена Замовити книжку | справи
search-tags справи
exit
```

## 3. Технічне завдання

Мета проєкту — створити систему для зберігання та взаємодії з записами адресної книги та нотатками.

### Основні вимоги

Персональний помічник повинен вміти виконувати такі дії.

1. Зберігати контакти з іменами, адресами, номерами телефонів, email та днями народження до книги контактів.
2. Виводити список контактів, у яких день народження через задану кількість днів від поточної дати.
3. Перевіряти правильність введеного номера телефону та email під час створення або редагування запису та повідомляти користувача у разі некоректного введення.
4. Здійснювати пошук контактів серед контактів книги.
5. Редагувати та видаляти записи з книги контактів.
6. Зберігати нотатки з текстовою інформацією.
7. Проводити пошук за нотатками.
8. Редагувати та видаляти нотатки.

Максимальний бал за основну частину командного проєкту становить 90 балів у разі, якщо коректно виконано всі умови основного чекліста.

#### Чекліст виконання проєкту

**Зберігання та управління контактами**

- [ ] Додавання нових контактів із іменами, адресами, номерами телефонів, електронною поштою та днями народження.
- [ ] Пошук контактів за різними критеріями (наприклад, за іменем).
- [ ] Редагування та видалення контактів.
- [ ] Виведення списку контактів, у яких день народження через задану кількість днів від поточної дати.
- [ ] Валідація номера телефону та електронної пошти під час додавання або редагування контакту.

**Зберігання та управління нотатками**

- [ ] Можливість додавання текстових нотаток.
- [ ] Пошук, редагування та видалення нотаток.

**Зберігання даних**

- [ ] Всі дані (контакти, нотатки) повинні зберігатися на жорсткому диску у папці користувача.
- [ ] Помічник може бути перезапущений без втрати даних.

### Додаткові вимоги

Функціонал проєкту можна розширити або змінити на власний розсуд. Для тих, хто реалізує основний функціонал, передбачено додаткове завдання.

1. Додавати в нотатки теги — ключові слова, що описують тему та предмет запису.
2. Здійснювати пошук та сортування нотаток за ключовими словами (тегами).

Додаткове завдання є необов’язковим. За реалізацію функціоналу з додаткового чекліста можна отримати 10 балів.

#### Чекліст додаткових вимог

**Зберігання та управління нотатками**

- [ ] Додавання тегів до нотаток.
- [ ] Пошук та сортування нотаток за тегами.

**Інтелектуальний аналіз**

- [ ] Помічник повинен вгадувати, що хоче від нього користувач, на основі введеного тексту та пропонувати найближчу команду для виконання.
